Windows 活動現場版｜操作只要三步

1. 下載 ZIP 後，先按「解壓縮全部」，放在活動電腦的內建硬碟。
2. 雙擊 start-website.cmd（或用 Edge / Chrome 開啟 index.html）。
3. 點任一站卡片，再按「選擇這一站的影片」，選電腦裡的 MP4 即可播放。

不需要改影片名稱，不需要將大影片上傳到聊天或 GitHub。
選取的影片只在電腦裡播放，不會上傳。六站可各自選不同檔案。
這次開啟期間會記住各站選擇；關閉或重新整理後，需要重新選取。
影片關閉時會停止播放。播放視窗內可調整音量、進度與全螢幕。
瀏覽器按 F11 可進入全螢幕（部分鍵盤需 Fn + F11）。

進階：如果想每次都自動找到影片，可將六支影片複製到 videos 資料夾，
依序命名 station-01.mp4 ～ station-06.mp4，就不必每次選取。
這六支正式影片尚未包含在此套件內；請使用同仁交付的檔案。
影片建議格式：MP4 / H.264 影像 / AAC 音訊。

活動前：接好 HDMI，確認 Windows 聲音輸出為大螢幕或現場音響，
關閉網路，逐站試播。先確認 Windows 沒有靜音；六支高畫質影片仍需實機確認順暢度。

此版本不修改公開網站，所有圖片與背景短片均在資料夾內，字型採 Windows 本機字型。
本機影片功能已以 Chromium 測試；啟動檔仍需在你的 Windows 電腦確認。
若系統不允許執行 CMD，直接右鍵 index.html → 開啟檔案 → Microsoft Edge。
