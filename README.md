# BMW 2026 旅行網站

這是由既有的「BMW_2026_旅遊網站_更新版.html」拆分而成的網站專案，並非重製網站。

## 使用方式
- 開啟 `index.html` 即可預覽（部分瀏覽器功能可能需透過本機網頁伺服器瀏覽）。
- `assets/images/` 包含原本 HTML 內嵌的圖片，重複圖片已共用同一檔案。
- 務必保留 `assets/images/` 相對路徑，不要單獨移動 `index.html`。
- Google Fonts 等外部資源需要網路連線。

## 修改範圍
這次只把 Base64 圖片改成相對路徑，未重寫版面、動態、文案與互動程式。
